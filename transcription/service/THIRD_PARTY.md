# sherpa-onnx

This module includes the Android JNI libraries and Kotlin API wrappers from sherpa-onnx v1.13.6.

- Source: https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.6
- Android release: https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.6
- License: Apache-2.0

Model weights are not bundled. Each downloadable model keeps its upstream license and pinned repository revision.
